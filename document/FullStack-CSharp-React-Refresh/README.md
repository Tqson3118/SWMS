# FullStack C# + React Refresh
Khóa ôn dành cho người đã học nhưng kiến thức rời rạc. Mục tiêu: tự viết, debug, kiểm thử và giải thích một ứng dụng chi tiêu .NET 10 + React/TypeScript, rồi dùng bằng chứng dự án để ứng tuyển. Không cam kết việc làm hoặc thời gian học cố định.

**7 chặng · 28 tuần năng lực · 84 bài nhỏ.** 12–18 giờ chuyên môn/tuần và English 30–60 phút/ngày. Dùng SQL Server, EF Core 10, JWT, Redis, Docker, GitHub Actions. Một project xuyên suốt; C++/NoSQL/Vue là đọc bổ sung.

## Cách học
1. Đọc [hướng dẫn cài đặt](setup.md) và [đặc tả dự án](project-spec.md).
2. Làm chẩn đoán đầu tuần không tra lời giải. >=5/6 quiz và hoàn thành bài code/gate thì rút ngắn phần đọc đã biết; không được bỏ feature hoặc security gate.
3. Học 3 bài/tuần, gõ và đổi input ví dụ; ghi expected/actual/debug.
4. Làm practice từ tệp trống, dùng phần hướng dẫn giải sau khi thử ít nhất 30 phút.
5. Làm project task và lưu bằng chứng theo acceptance. Quiz >=5/6, làm lại các câu sai sau 24h; English30–60 phút mỗi ngày,7 ngày/tuần.
6. Ôn thẻ sau 1, 3, 7, 14 ngày; giải thích lại code không nhìn AI.
