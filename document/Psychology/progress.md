## Hướng dẫn sử dụng

### Các cột theo dõi

| Cột | Ý nghĩa |
| :--- | :--- |
| **Core** | Phần *Học nhanh khi mệt* / Fast Track (30–45 phút) |
| **Deep Dive** | Bài đọc sâu, nghiên cứu tiêu biểu, phản biện |
| **Mini-Review** | Hai lần ôn giữa tuần (retrieval practice) |
| **Quiz** | Quiz cuối tuần + tự chấm bằng answer key |
| **Review lại** | Ôn lại khi cần (spaced review) |

### Trạng thái gợi ý

Ghi **một** trong các ký hiệu sau vào ô (hoặc thay bằng ngày `YYYY-MM-DD`):

| Ký hiệu | Trạng thái |
| :---: | :--- |
| `—` | **Chưa bắt đầu** |
| `▶` | **Đang học** |
| `✓` | **Hoàn thành** |
| `↻` | **Ôn lại** |

### Ba chế độ học (tham chiếu roadmap)

- **Mệt:** chỉ cần hoàn thành cột **Core**.
- **Bình thường:** **Core** + **Deep Dive** + **Mini-Review** + **Quiz**.
- **Có hứng:** như Bình thường; thêm case/journal tự nguyện (không có cột riêng — ghi chú cá nhân nếu muốn).

Case study / journal là **tự nguyện**; luôn có thể dùng **hypothetical case**.
