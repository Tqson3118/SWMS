## Phần A — Grammar: 50 điểm

### Q1. Chọn đáp án đúng (20 câu × 1đ = 20đ)

1. Ambition is the trait ______ pushes people to take risks. (who / which / whose / where)
2. She is the therapist ______ I trust most. (who / which / whose / who's)
3. The office ______ I work has no windows. (when / where / which / whose)
4. I remember the day ______ I failed my first driving test. (where / when / which / whose)
5. He is a manager ______ decisions are always explained. (who's / whose / who / which)
6. The study ______ Pittenger published in 1993 criticized MBTI. (who / whose / which / where)
7. My brother, ______ lives in Da Nang, is very easygoing. (that / which / who / whose)
8. Costa, ______ co-developed the Big Five, worked with McCrae for decades. (that / which / who / where)
9. People ______ oversleep usually skip breakfast. (which / whose / who / whom)
10. The questionnaire ______ we completed had fifty items. (who / whom / which / whose)
11. That was the summer ______ my confidence finally grew. (where / when / which / whose)
12. Resilience is the quality ______ helps you recover. (who / whose / which / where)
13. The colleague ______ I interviewed turned out to be witty. (who's / whose / whom / which)
14. My grandmother, ______ patience I still admire, raised me. (who / that / whose / which)
15. The clinic ______ I did my assessment is downtown. (when / which / whose / where)
16. A reliable friend is a person ______ never lets you down. (whose / who / which / where)
17. Narcissism is a set of traits ______ psychologists study. (who / whose / that / where)
18. The year ______ we moved was 2015. (where / when / which / whose)
19. Introverts are people ______ need quiet to recharge. (which / whose / who / whom)
20. The book ______ changed how I see people is *Quiet*. (who / whose / which / where)
