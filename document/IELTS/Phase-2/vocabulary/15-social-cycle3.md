## Bài tập trộn (24 từ — làm cuối ngày 11)
1. If someone gave you a small gift, you would owe them — that's ______. (có qua có lại)
2. If it were the last one, you would grab it — ______. (sự khan hiếm)
3. If everyone bought it, you would want it too — ______ ______. (bằng chứng xã hội)
4. If a doctor said it, you would believe it — ______. (độ tin cậy)
5. If propaganda repeated a lie, the lie would feel ______. (quen thuộc)
6. If a ______ were catchy enough, it would outlive the product. (khẩu hiệu)
7. If you showed me the data, I would be ______. (được thuyết phục)
8. If it helped them sell, they would ______ without shame. (thao túng)

---
**ĐÁP ÁN:** 1. reciprocity 2. scarcity 3. social proof 4. credibility 5. familiar 6. slogan 7. convinced 8. manipulate
