# 🗣️ Speaking Prompts — Phase 2 Month 3 (Social Psychology)

> Mỗi ngày 3-5 phút với AI voice (prompt 1 trong `Resources/ai-conversation-guide.md`). Xong LUÔN chạy prompt 2 (sửa lỗi) → chép 3 lỗi vào `Phase-1/error-log.md`. Tháng này: KỂ 2 TẦNG + TRANH LUẬN GIẢ ĐỊNH — Past Perfect cho việc trước, Past Simple cho dòng chính, câu điều kiện cho "nếu là bạn".

| Ngày | Chủ đề | Gợi ý câu |
|------|--------|-----------|
| D1 | One time I conformed | The group had decided before I spoke. I said... |
| D2 | Authority in my life | When the teacher insisted, I... I had never questioned... |
| D3 | A time I refused | I had thought about it before — so I said no. |
| D4 | (test) | — |
| D5 | Group rules | If you put people in a group, ... (Zero) |
| D6 | Predicting people | If the leader stays calm, followers will... (First) |
| D7 | My honest voice | If one person resists, others will follow. Once, I was that person / I wasn't. |
| D8 | (test) | — |
| D9 | If you were the subject | If I were in Milgram's room, I would... — I think. |
| D10 | Six buttons | If someone gave you a gift, you would feel... Which button works on you? |
| D11 | Khuyên bạn mình | If I were you, I would... |
| D12 | (TEST TỔNG #1) | Kể 1 thí nghiệm 2 phút |
| D13 | Tell an experiment | Milgram had told them it was about memory. Then... |
| D14 | Two-floor story | By the time X happened, Y had already... |
| D15 | An experiment I would stop | They had been running it for a week before anyone objected. I would have... (nói: I would stop it) |
| D16 | (test) | — |

| D18 | Ethics debate | If I were the experimenter, I would stop it — if I could see it from outside. |
| D19 | My boundary story | I drew a boundary. Before that, I had said yes to everything. |
| D20 | (test) | — |
| D21 | The room I know | That meeting... nobody had said "wait" — so I did. |

| D24 | (TEST TỔNG #2) | Kể + tranh luận 3 phút |

> **Mẹo tháng này:** tranh luận giả định xong LUÔN đuôi câu thật — *"I would refuse — but 65% said the same and obeyed."* Đây là kỹ năng "argue like a psychologist".
